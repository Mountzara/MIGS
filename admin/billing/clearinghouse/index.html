Clearinghouse · Go-Live

Claims don't go straight from your office to an insurer. They pass through a clearinghouse — a switchboard that checks each claim's format, forwards it to the right payer, and returns the payer's answer. You need exactly one to start.

Start here — you have not enrolled yet

Everything below this box is a control panel for after you're enrolled. Ignore it for now. There are four steps, in this order:

1
Pick one clearinghouse
Recommendation for your situation — solo practice, custom billing pipeline, Illinois (and possibly California): Claim.MD. It carries Medicare, Medicaid/Medi-Cal and commercial in one place, is priced for small practices, and doesn't require an enterprise contract.

Availity Essentials is the alternative worth knowing: free real-time eligibility with the Blues (BCBS IL, Anthem/Blue Shield CA) — many practices end up using Availity for eligibility checks and a second clearinghouse for claims. Stedi has the cleanest API if you later want maximum automation, but it is the most engineering-heavy option.

Costs and enrollment terms change — confirm current pricing directly with the vendor before committing.
2
Enroll with them — this is its own application
Like payer credentialing, not like signing up for a website. They will need your NPI, Tax ID / W-9, practice address, and your payer list. Expect back-and-forth, and expect per-payer enrollment: some payers (especially Medicare and Medicaid) require a separate EDI enrollment form before they'll accept electronic claims from your clearinghouse.
3
Get your credentials into this page
They'll issue an API key or account credentials. Those go in Clearinghouse credentials below. Nothing on this page can talk to a payer until that exists.
4
Test, then go live
Submit test claims first. The pipeline deliberately stays in test mode until you flip it — that switch is CLEARINGHOUSE_LIVE=1, and it exists so a half-configured pipeline can never send a real claim by accident.

You cannot skip step 2. Routing payers, posting remittances, and everything else below only work once a real clearinghouse account exists behind them.
